# スキマ簿記

税理士試験・簿記論を、休憩や移動のスキマ時間に軽く学べるWebアプリです。`index.html` 1ファイルだけで動きます（ビルド不要）。

## モード
- **仕訳ドリル 入門／本試験レベル** … 取引文を読んで、4つの伝票から正しい仕訳を選ぶ（10問）
- **勘定科目ふりわけ** … 60秒タイムアタック。資産・負債・純資産・収益・費用に仕分け
- **電卓いらずの計算** … 減価償却・経過勘定・貸倒引当金・償却原価法など。数字は毎回ランダム（5問）
- **理論○×** … 会計基準や表示区分の知識チェック（10問）
- **間違えた仕訳を復習** … 外した・分からなかった仕訳だけ出題、正解で卒業
- **用語じてん** … 仕訳の基本ルールと、約150語のやさしい解説（検索・分類つき）

どの問題にも「分からない」ボタンがあり、押すと答えと解説が出ます。問題文・解説・伝票の科目名のうち点線の付いた言葉は、タップすると意味が表示されます。

今日の問題数・連続日数・正答率・自己ベスト・復習リストは、claude.ai の Artifact として開くとアカウントに保存されます（再読み込みや別端末でも引き継ぎ）。それ以外（ファイル直開きや GitHub Pages）ではブラウザの localStorage に保存されます。

## 使い方
- `index.html` をブラウザで開く
- スマホで使うなら GitHub Pages（Settings → Pages → Branch を選択）で公開するとURLから開けます

## 問題を増やす
`index.html` 内の `JOURNAL`（仕訳）、`OX`（○×）、`ACCOUNTS`（勘定科目）、`GLOSSARY`（用語じてん）、`CALC`（計算問題ジェネレータ）に追記してください。
仕訳は `"借方科目:金額+借方科目:金額 | 貸方科目:金額"` の形式です。
